# 🌾 AgriPulse

### AI-Powered One-Stop Agricultural Equipment Repair & Maintenance

> **Don't just diagnose the breakdown. Recover the machine.**

AgriPulse is a farmer-first platform designed to reduce agricultural equipment downtime by connecting **AI-assisted diagnosis, technicians, spare parts, service centres, repair tracking, and preventive maintenance** in one ecosystem.

## 🚜 The Problem

When farm machinery breaks down, farmers often have to separately find:

* The right technician
* Spare parts
* Repair services
* Pricing information
* Emergency support
* Maintenance history

This fragmentation increases downtime, cost, and uncertainty.

## 💡 Our Solution

AgriPulse connects the complete repair journey:

```text
Farmer
  ↓
Problem / Voice / Image
  ↓
AI-Assisted Diagnosis
  ↓
Urgency
  ↓
Recovery Engine
  ↓
Technician + Parts + Service Centre
  ↓
Transparent Pricing
  ↓
Repair Tracking
  ↓
Machine Passport
  ↓
Preventive Maintenance
```

## 🤖 AI-Powered

AI helps understand farmer complaints and identify a **possible issue**, equipment context, and urgency.

AI is an assistant — **final mechanical verification remains with the technician.**

## 🧠 Recovery Engine

AgriPulse goes beyond diagnosis.

The Recovery Engine connects the problem with available repair resources using factors such as:

* Technician skills & certification
* Availability
* Service area
* Spare parts
* Service centres
* Urgency
* Pricing

### The difference:

> **AI doesn't just tell the farmer what might be wrong — AgriPulse helps find a path to getting the machine working again.**

## 🚀 Run Locally

```bash

cd agripulse-agricultural-equipment-repair

npm install

npm run dev
```

Configure required API keys through environment variables. **Never commit secrets to GitHub.**
